## Known name collision

Every live sim declares its own `--font-sans` (DM Sans) in unlayered CSS, which beats this sheet's layered `--font-sans`. The override layer therefore uses `--fsim-font-ui` for Inter. When Track R removes the sims' own declaration, `--font-sans` takes effect and `--fsim-font-ui` retires.
