# Curriculum drop-slot

Place the authoritative particle-physics course curriculum here (any format the
reviewer can read: .md, .txt, .pdf, .html, exported .csv/.xlsx sheets…). The
`review-pp-v2-sims` skill reads EVERY file in this directory as its top-priority
source of truth for scope, learning objectives, required affordances, visuals, and
inquiry questions.

Until a curriculum file is added, the reviewer falls back to
`.claude/skills/review-fermi-pp-sims/course-context.md` (the v1 planning-doc
distillation) and flags in every report that the authoritative curriculum was absent.
